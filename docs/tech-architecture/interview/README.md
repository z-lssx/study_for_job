# 技术面试材料

本目录面向项目作者，用于准备简历表述和技术面试。它不是开发 Agent 的实现事实源。

## 使用规则

- 每个结论必须能回链到 `decisions/`、`implementation/` 或验证交接。
- 先说明真实问题，再说明选择、替代方案、代价和验证；不把技术名词堆叠成亮点。
- 主动保留局限和演进触发条件，避免把本地 MVP 包装成大规模分布式系统。
- 工程事实变化时先更新事实层，再更新这里；发生冲突时以事实层为准。

## 当前材料

- [PostgreSQL 任务队列与 Worker](postgres-job-queue.md)：表拆分、并发领取、租约恢复、至少一次语义、幂等与有界指数退避。

## 项目总体定位

`study_for_job` 是单用户、本地优先的秋招面试准备 Web 应用。当前已实现的主要工程基础包括 PostgreSQL 唯一事实源、前后端分离模块化单体、投递闭环、AI Gateway 和 PostgreSQL 任务队列。其他规划能力只有在实现状态文档确认完成后，才能写入面试成果。
