# 项目技术案例

本文档从简历和技术面试视角持续提炼项目。内容必须来自已经实现并验证的代码、数据和测试结果。

## 项目定位

`study_for_job` 是一个单用户、本地优先的秋招面试准备 Web 应用。系统以面经情报为外部需求输入，并将其连接到个人的知识、算法、项目和实习准备过程。

## 当前架构主线

- PostgreSQL 作为唯一业务事实源
- 前后端分离的模块化单体
- PostgreSQL 任务表与独立 Worker 处理长任务
- 词法检索、向量检索和结构化查询按场景组合
- AI 负责提炼和表达，规则与数据库负责事实、统计和约束
- Agent 只用于需要多轮状态和动态决策的场景

以上是当前设计方向，不代表相应功能均已实现。实现状态以 `docs/implementation-status/` 目录中的状态文档为准。
