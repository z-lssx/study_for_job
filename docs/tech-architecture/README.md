# 技术架构文档

本目录保存供开发 Agent 理解系统和继续实现所需的工程事实。

## 文档入口

- [总体技术架构](overview.md)：系统级结构和长期边界。
- [关键技术决策](decisions/README.md)：重要取舍、替代方案和演进条件。
- [模块实现记录](implementation/README.md)：已实现机制、精确参数和验证事实。

## 维护原则

- `overview.md` 不记录每次开发过程。
- `decisions/` 只记录会影响后续实现的选择。
- `implementation/` 只记录已经落地并验证的机制。
- 只有影响行为、数据一致性、可靠性边界、性能、安全、成本或后续演进的重要参数才进入稳定文档。
- 文档采用增量维护，不因格式调整重写已有的有效决策。
