# 关键技术决策

本目录使用一项决策一个文件的方式记录重要技术取舍。只有当决定存在多个合理方案，并会影响架构、数据兼容性、可靠性、成本或后续扩展时才新增记录。

建议命名：`0001-short-title.md`。

每项决策包含：

- 状态：提议 / 已确认 / 已废弃 / 已替代
- 背景与问题
- 最终选择
- 考虑过的替代方案
- 选择理由与代价
- 对代码、数据和运维的影响
- 验证证据
- 后续演进条件

普通库用法、字段命名、CRUD 实现和可随时替换的局部细节不需要写成决策。
