# 项目开发治理

项目采用三层 AI 开发协作：

- [项目大总管规则](PROGRAM_MANAGER.md)：唯一逻辑大总管的宏观控制、持久状态、恢复协议和阶段总管派发。
- [阶段总管规则](AGENTS.md)：维护一个阶段内的计划、开发任务和阶段交接。
- [阶段文档生命周期](DOCUMENT_LIFECYCLE.md)：阶段结束时提炼、去重、归档和提交文档。
- 开发 Agent：按阶段总管生成的独立任务提示词完成实现、自验证、文档和提交。

启动提示词：

- [项目大总管启动与恢复提示词](prompts/program-manager.md)

整个项目只有一个项目大总管逻辑身份，同一时间最多一个活跃大总管对话。用户负责首次启动或明确替换该对话；替换是恢复同一角色，不产生第二个大总管逻辑身份。阶段总管由大总管通过 Codex 桌面任务工具顺序创建，阶段开发任务再由当前阶段总管创建。

项目大总管和阶段总管均可直接提交自己负责的治理文档；纯文档提交不再转派开发 Agent。
