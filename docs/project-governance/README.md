# 项目开发治理

项目采用三层 AI 开发协作：

- [项目大总管规则](PROGRAM_MANAGER.md)：维护宏观阶段、跨阶段依赖和阶段总管派发。
- [阶段总管规则](AGENTS.md)：维护一个阶段内的计划、开发任务和阶段交接。
- [阶段文档生命周期](DOCUMENT_LIFECYCLE.md)：阶段结束时提炼、去重、归档和提交文档。
- 开发 Agent：按阶段总管生成的独立任务提示词完成实现、自验证、文档和提交。

启动提示词：

- [第一代项目大总管启动提示词](prompts/program-manager-v1.md)
- [历史：第一代阶段总管启动提示词](prompts/manager-v1.md)

用户通常只需要手动启动项目大总管。阶段总管由大总管通过 Codex 桌面任务工具创建；阶段开发任务再由阶段总管创建。

项目大总管和阶段总管均可直接提交自己负责的治理文档；纯文档提交不再转派开发 Agent。
