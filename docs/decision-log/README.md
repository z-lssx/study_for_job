# 已确认产品决策

本文档只记录仍约束未来补丁的产品边界。开发过程、阶段管理和任务历史不属于产品决策。

## 产品定位

- 单用户、本地优先的桌面 Web 应用。
- PostgreSQL 是唯一业务事实源，浏览器状态不能替代领域持久化。
- 面经是全局情报层；目标与投递构成策略上下文；知识、算法、项目、实习是四条独立准备轨道。
- 以用户自主准备为主，系统负责提炼、组织、提醒和解释，不制造用户事实。

## 面试情报

- 支持公开、无需登录且来源许可明确的页面，以及用户直接粘贴正文。
- 保存原文、来源、处理状态、结构化轮次/内容块、规范题出现记录和证据区间。
- 失败必须保留可诊断原因，并允许补正文恢复。
- 重复 URL 或内容不得产生重复业务事实。
- 原作者答案保留为来源内容，不等同于标准答案。
- 高频统计来自原始 occurrence，不被用户后续编辑污染。
- AI 提炼可供用户修订，但用户修订只影响个人准备层，不反写原始证据。
- 不登录、不绕过验证码、不扩展为通用爬虫；始终保留手动正文降级入口。

## 知识准备

- 目标是把外部资料和高频问题转成可口述、可追问、可复习的内容，不建设百科式标准答案库。
- 支持题目、知识点、外部资料、口述版本、高频追问、踩坑点和轻量掌握状态。
- 支持随机单题练习，不扩展为多轮模拟面试。
- AI 草稿支持用户编辑，且不能覆盖用户确认内容。
- 不使用虚假的统一能力分数。

## 算法准备

- 练习发生在外部平台，本项目不提供代码编辑、运行或在线判题。
- 保存题目链接、状态、卡点、复盘、最近练习和规范题关联。
- 面经频率只能作为弱相关信号，不能替代用户掌握状态。
- 不实现 LeetCode 账号同步，除非未来形成单独确认的产品需求。

## 项目与实习

- 以经历证据包为核心，表达版本由真实事实和材料派生。
- 保存职责边界、技术选择、困难与取舍、可核实指标、STAR/表达版本、材料和追问。
- AI 可以整理、总结和提示缺口，但不得编造经历或覆盖用户修订。
- 已确认版本保留历史，不做静默覆盖。
- 项目和实习共享可信原则，但不强制使用完全相同的数据模型或页面模板。

## 投递记录

- 投递是用户手动维护的求职流程，不是知识输入主源。
- 保存公司、岗位、渠道、阶段、关键日期、下一步行动、备注和链接。
- 不自动爬取岗位。
- 投递只在明确临近面试上下文中作为准备策略的同档弱信号；普通 `key_date` 不得被猜测为面试日期。

## 策略与 AI

- 准备评估由用户在页面显式触发，不做面向用户的定时生成、轮询或推送。
- 当前策略规则优先、排序稳定、原因可解释，并返回来源和证据限制。
- 情报频率、投递阶段、AI 草稿、表达版本和用户维护状态保持各自语义，不合并成统一评分。
- AI 输入只取必要摘要与有界证据，不读取全量面经正文制造成本和幻觉。
- 动态 prompt 只开放少量关键场景；管理端只保留 prompt、参数、运行诊断和 token/trace 账本，不扩展为通用聊天或运营后台。
- DeepSeek-compatible provider 已作为可替换边界，真实模型标识和 embedding 供应方式按真实需求决定，不硬编码未经验证的值。

## 导出与数据所有权

- 支持用户主动生成 Markdown 和 JSON 事实快照。
- 两种格式必须来自同一个只读事实快照，保留稳定 ID、关系、用户修订、确认状态和证据边界。
- `as_of_date` 是导出声明基准，不伪造数据库并不存在的历史版本。
- 本地优先不能形成数据锁定，用户事实应可读、可导出。

## 客户端与设计

- 桌面 Web 是唯一正式支持端；保留基础响应式，但不规划移动端专属导航、PWA、离线同步或原生客户端。
- 应用采用“今日重点首页 + 独立投递页 + 可收起左侧工作台导航”。
- 深层内容使用真实 URL；抽屉用于快速上下文操作，弹窗用于短任务，长编辑进入独立页面。
- 视觉保持安静、温暖、低干扰和舒适字号；禁止全局网格、海报式巨型标题、普遍小字号和长页面无层级平铺。
- 四条准备轨道使用统一设计语言，但必须按各自真实任务分别设计。
- 完整交互规范见 `docs/design/frontend-redesign.md`。

## 当前明确不做

- 登录和多用户权限体系
- 面向用户的定时任务或推送
- 自动岗位爬取
- 在线判题和 LeetCode 同步
- 通用聊天型智能体
- 重型运维、发布回滚和完整备份恢复平台
- 移动端专属产品能力
- 在没有真实查询样本与质量目标时提前锁定 embedding/pgvector

## 延期能力

- 同义/语义召回、embedding、pgvector 与真实检索质量评估。
- 多轮模拟面试、项目/实习深挖 Agent 和 LangGraph checkpoint。
- 更复杂的公司差异化画像、知识图谱可视化和自动评分。
- 最近策略快照持久化与跨刷新恢复。

延期不等于已实现。当前限制和安全风险统一见 `docs/maintenance/known-issues.md`。

## 开发协作方式

MVP 完成后采用单任务补丁式开发，不再使用项目大总管、阶段总管、阶段计划或任务工作区。具体规则见 `docs/maintenance/README.md`。
