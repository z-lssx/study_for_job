# 实施状态目录

本目录是跨对话传递开发状态的唯一入口。内容可按阶段、领域和任务继续拆分，不要求所有进度放在同一个文件中。

- 本目录的状态文档：记录对应范围的已完成内容、阻塞和下一步依赖。
- `tasks/`：总管 Agent 创建的子任务说明和完成记录。
- `roadmap.md`：阶段路线图与阶段目标。
- `queue.md`：当前任务队列、依赖和状态。
- `task-workspaces/`：从 T002 起保存每个任务的计划、实施/审查过程和验证交接文档。
- `management-plans/`：每任总管在派发任务前维护的阶段任务规划、完成边界和交接条件。
- `handoffs/`：主要阶段完成或总管上下文需要接力时的正式交接文档。
- `program-status.md`：项目大总管维护的宏观阶段状态、下一阶段与跨阶段风险。
- `archive/`：按阶段保存已被稳定事实源替代、但仍需追溯的过程文档。

总管 Agent 负责维护总体状态；开发 Agent 在完成任务后只更新与本次工作相关的事实，不重新规划整个项目。
