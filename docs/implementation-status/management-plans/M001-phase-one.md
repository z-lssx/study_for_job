## 明确非范围

- 本任不进入阶段二的面经公开来源抓取、正文降级、抽取、去重、归一化、检索或频率统计。
- 不为 T004 固定追加独立审查；由开发 Agent 自行完成与风险相称的验证。
- 不处理 embedding 供应方案，不启动多轮 Agent、移动端、多用户或通用聊天能力。
- 总管不读取源码、diff 或亲自执行测试，只消费任务摘要和状态文档。

## 子任务派发原则

- 共享工作区顺序派发，前一任务提交/推送并确认工作树无遗留后再创建下一任务。
- 任务提示词包含完整边界、验收、自验证、文档更新和结构化反馈。
- 前端设计/视觉任务显式绑定 `@frontend-design`；T004 是后台机制任务，不要求新增前端设计。
- 授权开发 Agent 在任务完整、验证通过、范围和敏感信息检查通过后提交并推送，并主动反馈来源管理对话。
