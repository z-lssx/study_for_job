# T007 计划：规范题、出现事实、人工修正边界与频率统计

状态：已完成

## 目标

在 T006 已成功抽取的 `question_candidates` 与 `evidence_spans` 上建立规范题层：每个原始候选形成不可被人工修订覆盖的出现记录，规范题映射与人工合并/拆分保持独立，并从出现记录聚合可回链的频率事实。

## 实施边界

- 复用 `interview_documents`、`extraction_runs`、`interview_rounds`、`document_chunks`、`question_candidates` 和 `evidence_spans`，不复制文档身份或正文。
- 使用确定性文本归一化建立初始规范题与映射；不调用远程模型，不引入 embedding、pgvector、混合检索或频率快照基础设施。
- 原始 occurrence 只绑定候选、文档、轮次、块和证据，人工操作只调整独立映射层；合并、拆分和直接映射均保留修订事实。
- 同一成功抽取运行可重复刷新；由数据库唯一约束和短事务 upsert 保证同一文档/轮次内重复候选只计一次。
- 页面沿用现有面试情报风格，提供规范题列表、频率、证据下钻和人工映射操作；不进入准备轨道或导出能力。
- 不修改 T005 抓取、robots、SSRF、代理/DNS、清洗或 hash 风险治理，也不把延期风险写成已解决。

## 交付物

- PostgreSQL 增量迁移、ORM、归一化/聚合服务、API 与改动相关测试。
- 面试情报页面的规范题频率视图、证据回链和人工合并/拆分/映射入口。
- 轻量迁移/API/usage 隔离冒烟与页面人工验证；不运行 `npm run build`。
- `implementation.md`、`verification-and-handoff.md` 和稳定技术实现文档。

## 验收重点

1. 同一文档/轮次内重复抽取或刷新不重复计数，不同文档的等价问题可聚合。
2. occurrence 是不可污染的出现事实；人工合并、拆分或改映射不更新候选文本、位置或证据。
3. 频率列表与详情可回到文档、抽取运行、轮次、内容块、候选和 evidence span。
4. 不确定或人工拆出的映射可保持待确认，不强行归并。
5. usage 数据库只应用结构迁移，不注入开发规范题或修订事实。
