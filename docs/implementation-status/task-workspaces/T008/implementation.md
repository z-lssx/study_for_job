# T008 实现记录

## 变更

- 新增 `007_intelligence_search.sql`：启用 `pg_trgm`，为规范题、出现原文和搜索向量建立 GIN/表达式索引。
- 新增搜索仓储与 API：结构化过滤后使用精确包含、PostgreSQL FTS 和 trigram 候选路径排序；结果携带原文事实链路和可解释匹配路径。
- 新增质量状态 API：报告数据量、精确检索可用性、同义召回证据是否充分和不确定性结论。
- 面试情报工作区新增检索与质量面板，展示过滤项、来源、轮次、内容块和 evidence span 回链。

## 数据语义与幂等

搜索只读 `canonical_questions`、`question_occurrences`、映射和 T005/T006 证据表，不写入任何事实。重复请求只重复读取；映射修订仍只改变映射层。trigram 结果明确标记为候选，不等价于已证明的同义语义召回。
