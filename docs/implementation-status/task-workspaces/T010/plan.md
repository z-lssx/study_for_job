# T010 任务计划：算法轨道最小闭环

## 目标

提供外部算法题单、刷题状态、卡点与错题复盘、轻量单题随机练习入口，并保留题目来源和用户修订权。

## 进入条件与事实源

- 依赖 T009 已交付且其知识入口/共享状态边界稳定。
- 完整读取根 `AGENTS.md`、`README.md`、产品/决策/架构文档、阶段状态文档、M002 handoff 和 T009 handoff；semantic recall、embedding/pgvector、RAG 均为 `unproven`。

## 范围

- 复用现有数据流，维护题目来源 URL/平台、难度或标签（若已有）、刷题状态、错题原因/复盘文本和最近练习时间。
- 提供一次只返回/练习单题的随机入口；允许用户手动修订状态和复盘。
- 可解释关联阶段二规范题/主题，但不得把情报频率当评分真相。

## 非范围与验证

不做在线编辑器/判题、LeetCode 账号同步、定时推送、多轮模拟面试、统一评分或语义召回；不运行 `npm run build`，不写页面访问脚本。完成 `implementation.md` 与 `verification-and-handoff.md`，执行相关静态/单元验证和 `git diff --check`，未执行项如实记录，提交推送仅限 T010。
