# T010 实现记录：算法准备轨道

## 范围

- 增加可维护的算法题单数据边界：题目标题、来源、难度/标签、用户状态与错题复盘字段。
- 提供列表、创建、修订、练习记录和单题随机入口；随机接口每次最多返回一题。
- 允许显式关联阶段二规范题（`canonical_question_id`），返回规范题文本与出现次数作为可解释参考，不把频率当作评分。
- 增加桌面端算法工作区入口，复用现有 API 请求与本地用户修订模式。

## 非范围与约束

- 不实现在线编辑器、在线判题、LeetCode 账号同步、定时推送、多轮模拟面试、统一评分或语义召回/embedding/pgvector/RAG。
- 不修改 T009 知识卡片的数据流；不运行 `npm run build`，不编写页面访问脚本。

## 实施步骤

1. 新增 `009_algorithm_track.sql` 迁移与 `AlgorithmProblem` ORM 模型。
2. 新增 `/api/algorithms` FastAPI 路由，约束输入、状态和来源字段，落实用户修订边界。
3. 注册路由并新增前端 API/工作区组件，提供单题随机与练习记录按钮。
4. 执行静态编译、相关测试（若环境可用）及 `git diff --check`，记录未执行项。
