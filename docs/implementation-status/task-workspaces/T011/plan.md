# T011 任务计划：项目实践证据轨道

## 目标

建立项目证据包、表达版本、版本历史与岗位考点/面试情报的可解释关联，用户事实始终为唯一真相。

## 进入条件

- T009/T010 已完成并回传 handoff；共享入口稳定。
- 必读根规则、README、产品/决策/架构、阶段状态、M002 handoff 及 T009/T010 handoff。

## 范围

项目基本事实、个人职责/边界、技术选择、难点取舍、可核实指标、岗位考点映射、30 秒/2 分钟表达版本、追问树和版本管理；AI 仅生成可编辑草稿并保留来源与用户确认状态。

## 非范围与验证

不编造事实、不实现通用 Agent/RAG/语义召回、不做策略导出或多轮模拟面试；不改既有情报事实。不得运行 `npm run build`，不写页面访问脚本。完成任务工作区文档、相关静态/单元验证、`git diff --check`，如实记录未执行项并提交推送。
