- 事实、表达和情报只通过 ID 关联，不把 occurrence 频率写成能力评分，也不让情报改写用户事实。
- 版本创建默认引用当前最新版本，已确认版本只读；用户需要变化时创建新版本，保留可追溯历史。
- 当前没有 AI 调用。`ai_draft` 只作为未来可识别来源，必须先待核实；用户通过独立确认动作控制最终版本。
- T011 只提供与现有知识/算法页面风格一致的桌面最小入口，整体沉静化与信息层级统一留给已计划的 T013。
